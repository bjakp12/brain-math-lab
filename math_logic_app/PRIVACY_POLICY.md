# Kebijakan Privasi — Brain & Math Lab

Terakhir diperbarui: 30 September 2026.

**Ringkasan: aplikasi ini bekerja 100% offline dan tidak mengumpulkan,
mengirim, atau membagikan data pribadi apa pun.**

1. **Data yang disimpan** — Nama profil, progres belajar, XP, dan antrean
   latihan tersimpan **hanya di perangkat Anda** (penyimpanan lokal).
   Tidak ada akun, tidak ada login, tidak ada pelacakan iklan.
2. **Jaringan** — Aplikasi tidak mengirim data ke server kami. Satu-satunya
   akses jaringan adalah unduhan font (Google Fonts) oleh sistem operasi.
3. **Anak-anak** — Aplikasi edukatif, aman untuk semua umur, tanpa konten
   buatan pengguna, tanpa chat, tanpa pembelian dalam aplikasi.
4. **Penghapusan data** — Hapus lewat menu Pengaturan → Bersihkan Cache, atau
   hapus instalan aplikasi untuk menghapus seluruh data lokal.
5. **Perubahan** — Perubahan kebijakan akan dicantumkan di halaman ini
   beserta tanggal pembaruan.
